# PE Installer（pe_Installer）

> Windows 系统离线安装工具 — 纯 C + Win32 API 编写，单文件即可使用

## 功能说明

- 支持 **UEFI / Legacy(BIOS)** 两种固件模式自动检测
- 支持从 `install.wim` / `install.esd` / `win10_*.wim` / `win11_*.wim` 等 ISO 内镜像文件安装
- 可通过 URL 直接下载 ISO，自动挂载并识别可安装镜像
- **ViaPe 模式**：暂存到数据盘 → 写 BCD one-shot → 重启进 WinPE → PE 内自动执行 `dism /Apply-Image` + `bcdboot`，全程无人值守
- **降级直装模式【内测阶段）**：当同目录下 `boot.wim` / `winpe_amd64.wim` 均不存在且目标为非系统盘时，跳过 BCD/PE 注入，直接在正常系统内执行 `dism /Apply-Image`，不重启、不进 PE（目标为系统盘时仍走 PE 内核或需备份数据）
- **升级推送（v70 新增）**：启动时后台检查 GitHub Release，发现新版弹出更新日志框，用户可选择"查看并更新"或"暂不更新"（仅正常系统端触发，PE 端和 `/auto` 全自动模式绝不联网）
- 支持 `imagex` / `wimlib-imagex` 备用释放工具（应对第三方精简 PE 缺少 DISM 的情况）
- 支持自动识别 ISO、自动下载、自动安装（`/auto` 模式用于 PE 端全自动）

## ⚠️ 重要警告（必读）

> **本工具处于测试阶段，发布的版本存在一定问题，强烈建议：**
>
> 1. **先在虚拟机中测试**，确认安装流程无误、目标盘符正确后，再在主机会上操作。
> 2. **务必先备份重要资料**——任何分区/卷操作一旦执行，数据无法恢复。
> 3. **执行过程一定要仔细核对盘符**——软件会展示目标盘卷标、文件系统、总容量，请在确认框内核对无误后再点"确定"。
> 4. 目标为 **系统盘（当前运行盘）** 时，必须使用 PE 内核（`boot.wim` 或 `winpe_amd64.wim`），否则将触发降级直装——降级直装对系统盘**数据会被清空**，风险极高，操作前务必备份。
> 5. 目标为**非系统盘**时，Windows 允许直接写入，但目标分区数据仍会被覆盖，同样需要备份。

## 支持系统

| 项目 | 说明 |
|---|---|
| 最低系统 | Windows 10 1607 及以上（含 Win11 24H2） |
| 推荐系统 | Windows 10 22H2 / Windows 11 24H2 |
| PE 内核 | 必须为**标准 ADK WinPE**（内含 `winpeshl.exe` + `wpeinit.exe`）；"微PE工具箱"等多 Index 合集 WIMBOOT=0 无法引导，不能使用 |
| 架构 | 仅支持 amd64（x64） |

## 使用流程（正常系统端）

1. 运行 `PEI_Launcher.exe`（或 `PE_Installer.exe`），程序自动检测固件模式
2. 选择镜像文件（`install.wim` / `install.esd` / 完整 ISO）或填入下载 URL
3. 选择目标盘符，程序展示目标盘卷标/文件系统/容量，请**核对**
4. 点"开始安装"→ 确认框 → 软件暂存镜像到数据盘 → 写 BCD → 提示"即将重启进 PE"
5. 用户点确认 → 系统重启 → PE 内自动执行 `dism /Apply-Image` + `bcdboot` → 安装完成重启即可使用

> 若同目录下无 `boot.wim` / `winpe_amd64.wim` 且目标为非系统盘，将自动走**降级直装**路径（步骤 5 变为直接 `dism` 安装，无需重启进 PE）。
